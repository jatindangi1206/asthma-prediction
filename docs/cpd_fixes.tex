\section{Status and scope}
This records an \textbf{initial candidate fix}, not a validated CPD release.
The issue IDs refer to \code{docs/cpd_issues.tex}; that audit is retained as the
pre-fix baseline. No Python code, imports, tests, selftests, byte-compilation,
simulations or data processing were executed for this change, at the user's explicit
request. Regression test source is provided for later execution. Static syntax and
source inspection cannot establish numerical correctness or clinical performance.

The implementation scope is the five CPD adapters, shared CPD fitting/calibration,
the detection step and necessary CPD-specific integration, reporting and test code.
The join change is conditional on the new CPD schema: non-CPD aggregation retains
its existing behavior. Classifiers, smoothers, encoders, forecasting, labels,
eligibility, patient splitting, task definitions and horizons are not changed.

Both pipeline documents retain their intended role: \code{pipeline.pdf} specifies
the research paths and controlled comparisons; \code{pipeline.tex} explains fitted
patient preprocessing, forward inference and clinical classifier separation.
Candidate CPD still emits per-reading artifacts, feeds daily features to the same
join/model/evaluate stages, uses no clinical labels, and remains reusable across
folds. Missing detector output never removes a labelled day or patient.

\section{Design decisions and reasons}
\begin{enumerate}
\item \textbf{History is bounded by timestamps.} Null builders receive an exclusive
activation cutoff and a lower bound. Whole-day selection alone cannot enforce
causality at mid-day arming. Only completed abnormal dates affect calibration.
\item \textbf{H8 is a real-observation boundary.} Use the existing shared
\code{assign_chunks}, not a second threshold implementation. BOCPD/HMM and Kalman
monitoring reset evidence at chunk boundaries, because the gap itself is not an
observed physiological change. Kalman CUSUM also resets across missing nominal steps
(gap greater than 1.5 steps), conservatively avoiding accumulation across disconnected
excursions. This changes sensitivity and requires recalibration.
\item \textbf{Closed bins publish forward.} A median is available at its declared
bin close, not at its last included reading. Terminal open bins are omitted. Holders
must match the current chunk, satisfy current settling, and expire after one nominal
step. KCPD evaluates at actual eligible arrivals rather than backdating scheduled
clock events. Its optional second binning layer is rejected; shared detection
preprocessing is the single binning layer.
\item \textbf{Retain raw support independently.} Detection merges the original raw
channel with transformed support. Raw nightly drift and STS use complete raw history,
not the transform's finite-output mask. Artifact channel identity is explicit, and
raw measurements remain available to the model. Contradictory raw/transform source
generations must not be silently mixed.
\item \textbf{Refit in compatible coordinates.} At each daily normalization refit,
causally replay the bounded healthy history to initialize the new OU state. Old
normalized latent means/covariances cannot be carried unchanged into new coordinates.
Store fitted t scale as well as degrees of freedom and use both in HMM likelihoods.
HMM remains forward-only with fixed dwell/variance-ratio parameters: no full-record
EM or Viterbi is introduced.
\item \textbf{Insufficient history means unavailable.} Do not reintroduce excluded
abnormal history or silently fall back to all past dates. After nonwear at least as
long as the baseline window, restart burn-in in a new epoch. Short healthy windows
do not produce zero-centered unit-scale pseudo-baselines. Failed/insufficient null
calibrations disable the affected simulated streams, with a recorded reason.
\item \textbf{Conservative degeneracy guard.} Keep the event-rate envelope but add
a default maximum 10\% per-stream null occupancy, declared in the shared CPD
\code{max_null_occupancy} setting. This candidate guard prevents an almost
always-on flat-score solution from satisfying a low event budget. It is a declared,
keyed engineering guard, not a clinical target or empirically tuned optimum. Neither
per-stream occupancy nor a null fit guarantees a real-world ensemble alarm rate.
\item \textbf{Missing scores cannot alarm.} Hit masks require finite scores and
thresholds. Threshold-relative excess uses a bounded denominator even for zero or
negative thresholds. The representative ensemble phenotype follows declared method
order rather than comparing unlike probability/score magnitudes. Every individual
detector output remains available; representative phenotype is not a diagnosis.
\item \textbf{Nightly verdicts are explicit impulses.} Decide each completed night
using only its own available sleep observations; fallback uses 00:00--06:00 readings
but publishes no earlier than the common noon decision time. Enumerate calendar
nights even without readings on the following date. Do not defer verdicts through
settling or more than a day of nonwear. Distinct consecutive alarm nights remain
distinct; held magnitudes expire after a day. Nightly drift keeps its analytic
threshold as an explicitly unvalidated per-night approximation; simulated exposure
and eligible-night exposure are not silently equated.
\item \textbf{Exposure is a declared proxy.} Retain nominal observed-support minutes,
not an invented duration bridging nonwear. Within an HR bin, cap support at bin
width and actual observed nominal minutes. Calibration, fit records and reports
name this convention; it is not proof of actual continuous wear.
\item \textbf{Failures preserve population.} A patient exception yields retained raw
support and missing CPD features with failed status. Other patients continue.
Artifact completeness reports failures; uncaught coordinator errors mark the artifact
failed. A partial artifact is not a validated successful experiment.
\item \textbf{Version all result-affecting CPD dependencies.} Hash shared CPD code,
configuration, segmentation and actual channel/state file contents. Store the new
CPD logic/schema generation. Never reuse pre-fix CPD artifacts as candidate results.
\end{enumerate}

\section{Compatibility and recomputation}
The detector contract still supplies anomaly, phenotype, magnitude and severity
arrays. Optional score/availability diagnostics are additive. Steps remain independent;
the only existing cross-step reader exception is unchanged. CPD-specific join changes
are required to make event counts and model-variable preservation consistent with
both pipeline documents. No labels or clinical probability thresholds are changed.
The join logic version gains a CPD-only \code{-cpd_candidate_1} suffix; baseline
and non-CPD join cache versions remain unchanged. Raw-versus-artifact value checks
reject contradictory input generations before combining them. Disabled detectors
and unavailable periods yield missing flags/magnitudes, not fabricated negative
observations; availability remains explicit. Event calibration and aggregation both
terminate events at unavailable rows and declared gaps.
Old CPD artifacts and results are historical. Rebuild detection and dependent joins,
models and evaluation on the data machine; use exact keys when selecting artifacts.
Do not combine old and candidate event-count columns in one reported comparison.
